Star Hop — the same tiny agent-built game on day one and after a week of daily updates. Day 1: one little ghost, one star, bare ground. Day 7: the same map and the same start, but now with patrolling spike enemies, eight stars, sparkle particles, a night sky and a HUD. The camera never moves — the change is the whole story. The video cuts between the identical opening moments a week apart, closes on the new build actually being played to a win, and ends with make.fun's referral card. Play the game yourself in `game/index.html`.

## Run it

```sh
mkdir -p out && MAKEFUN_BOT_DIR=. MAKEFUN_OUTPUT_DIR=out node main.ts
```

This copies `VIDEO.json` (the TikTok address of the video) to `out/VIDEO.json`. To play Star Hop, open `game/index.html` in a browser — Arrow keys / A D to move, Space to jump, collect the stars, dodge the spikes, reach the golden goal star.
